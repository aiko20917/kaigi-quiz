海技QUIZ v0.3（テスト版）

v0.2からの変更:
・学習履歴をJSONファイルとしてバックアップ・復元できます。
・問題ID重複と必須項目の欠落を検出します。
・問題読み込み失敗時に診断メッセージを表示します。
・公開テスト用の自作サンプル問題3問を収録。実際の試験問題ではありません。

使い方:
1. 5ファイル（index.html / style.css / app.js / questions.js / README.txt）を同じフォルダに置きます。
2. index.htmlをブラウザで開きます。
3. GitHub Pagesでは、v0.2と差し替える前にローカルでテストしてください。

重要:
・保存キーはv0.2と同じ「kaigi-quiz-v01-grades」です。同じURL上で差し替えた場合、以前の履歴は残ります。ただしサンプル問題のIDは別なので集計に表示されません。
・v0.2から公開サイトを上書きする前に、v0.2の学習記録をバックアップする機能はないため、元のファイル・URLを維持して慎重に作業してください。
・JSON復元は既存の履歴を上書きします。先にバックアップしてください。
・APIキーはHTML/JSに入れないでください。
・書籍の問題文を公開する際は権利を確認してください。
