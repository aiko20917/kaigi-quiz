海技QUIZ v0.4 テスト版

新機能：問題JSONの一括追加・追加問題のエクスポートと削除、問題ごとの採点回数・最終日時、v0.3形式(version:1)のバックアップ読込、v0.4形式(version:2)のバックアップ。

index.html / style.css / app.js / questions.js は同じフォルダに置いてください。
「sample-import.json」は問題追加テスト用です。問題の一括読み込みから選んでください。

注意：追加した問題はこのブラウザのlocalStorageに保存されます。GitHubに公開された全員共通の問題にはなりません。別端末への移行には「追加問題をダウンロード」したJSONも必要です。
採点履歴バックアップには問題本文は含まれません。
旧版の採点キー kaigi-quiz-v01-grades を維持します。v0.3と同じURLで実行すると記録を共有します。
公開用には自作サンプル問題のみ同梱。書籍由来の問題は権利確認前に公開しないでください。
GitHubへは別フォルダ v04-test/ にアップロードしてください。
